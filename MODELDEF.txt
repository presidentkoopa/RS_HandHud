// RS_HandHUD -- the wrist readout.
//
// RLVR'S MESHES, AT RLVR'S OFFSETS. w_dial.md3 and w_belt.md3 are authored for
// a hand at Offset 0,-24,-10 and Scale 1 -- his holohud.txt says so -- so they
// arrive the right size and in the right place with nothing guessed. The unit
// quads that were here before (rs_plate.obj, rs_bracer.obj) were 2x1 map
// units, about five centimetres, which is why they had to be scaled to be seen.
//
// AND THAT SCALING IS WHAT WENT WRONG. PlacementCVars' _scale is a RAW
// MULTIPLIER -- r_data/models.cpp assigns wPlaceScale = sc and multiplies it
// straight into objectToWorldMatrix.scale. 100 is a hundred TIMES size, not a
// hundred percent. The plate was four metres across sitting beside the hand,
// which reads exactly like a billboard parked in the distance. That 100 came
// from cranking the slider to maximum while the plate was blank, and shipping
// it as a default made it permanent.
//
// THE PREFIX CHANGED FROM rs_handhud_* TO rs_hh_* ON PURPOSE. These are `user`
// cvars, so a value already in doomxr.ini beats any new default forever. The
// only way to stop a saved 100 from applying is to stop asking for that name.
//
// Everything else is the wire the hands and the reload magazine already use:
// UseHandOffsets puts the model at the hand, PitchOffset 90 stands it up, and
// BaseFrame -- last, always -- is what a +DECOUPLEDANIMATIONS actor's model
// lookup reads. Without it the psprite falls through to the sprite path and
// draws nothing.
//
// Scale X is negated on the main hand exactly as the hand models negate it:
// one mesh, mirrored, rather than two.
