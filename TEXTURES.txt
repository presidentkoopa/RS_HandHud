// RS_HandHUD -- glyphs for the LAYERED renderer.
//
// Ermac's wrist HUD draws numbers as sprites on psprite layers, one layer per
// digit, and it works because it asks nothing of the engine beyond what every
// weapon already does. His art (WH00..WH11) is not in the build we have -- zero
// lumps -- so the same mechanism is fed from the iwad instead, which is always
// present and needs no author.
//
//   STTNUM0-9   14x16   the big red status-bar digits
//   STYSNUM0-9   4x6    the small yellow ones
//   STTPRCNT    14x16   the percent sign
//
// Frames run A..J for 0..9, so the handler picks a digit with
// FindState("Digits") + value and never needs a jump chain.
